1. System Overview

LABTRACK is a cloud-hosted asset management system composed of a web administration dashboard, an Android mobile application, and a Supabase backend (PostgreSQL database, authentication, file storage, row-level security, and RPC functions). Instructors scan QR codes on lab equipment to view details, request bookings, report defects with photos, and communicate with administrators through ticket-based messaging.

5. Key Backend RPC Functions (Business Logic)

Critical workflows are enforced through PostgreSQL RPC functions rather than direct table writes:

  • resolve_asset_by_qr_code — QR-scoped asset lookup for mobile users
  • regenerate_asset_qr — Atomic QR replacement with audit logging
  • create_booking, cancel_booking, decide_booking, checkout_booking, return_booking — Booking lifecycle
  • create_defect_report, triage_defect_report — Defect workflow
  • ensure_ticket_thread, send_ticket_message — Ticket messaging
  • mark_notification_read — Notification read state
  • hook_restrict_signup_by_email_domain — Auth hook for domain-restricted registration
